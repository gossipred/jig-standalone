# JJ Jig Toolings Chinese Handoff Guide

This folder contains the standalone Chinese customer handoff guide.

這個資料夾是單獨提供給客戶的中文移交安裝說明，不放進 Windows zip 移交包。

## Files

- `治具及模具管理系統_中文移交安裝說明.docx` - Word version for customer reading
- `中文移交安裝說明.md` - editable Markdown source
- `tools/build_chinese_handoff_docx.py` - DOCX generator

## Note

The content explains:

- Windows installation flow
- Java 17 and MySQL requirements
- How to start and stop the system
- LAN connection planning
- Account roles and default accounts
- Backup method
- Troubleshooting
- Customer handoff checklist
