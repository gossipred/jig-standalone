# 治具及模具管理系統：中文移交安裝說明

文件版本：2026-05-22  
系統名稱：Jig & Toolings Management System / 治具及模具管理系統  
適用環境：Windows 10 / Windows 11，作為公司內部伺服器使用

## 1. 這套系統如何交給客戶？

這套系統不是每一台電腦都要安裝一次。最簡單的方式是：

```text
指定一台 Windows 電腦當作系統主機
        ↓
主機安裝 Java 17 + MySQL
        ↓
主機啟動治具及模具管理系統
        ↓
其他同事用瀏覽器連線使用
```

例如客戶指定的主機 IP 是：

```text
192.168.1.50
```

其他使用者只要在瀏覽器輸入：

```text
http://192.168.1.50:8080
```

就可以登入使用。

## 2. 客戶需要準備什麼？

客戶只需要準備一台固定開機的 Windows 電腦，建議當作內部小伺服器。

| 項目 | 建議 | 說明 |
| --- | --- | --- |
| 作業系統 | Windows 10 / 11 | 一般辦公室電腦即可 |
| Java | Java 17 | 系統主程式需要 Java 17 執行 |
| 資料庫 | MySQL Server 8.x | 儲存帳號、治具、模具、異動紀錄 |
| 瀏覽器 | Chrome / Edge | 使用者操作系統 |
| 網路 | 公司內部 LAN | 其他同事透過 IP 連線 |
| 備份空間 | 外接硬碟或公司備份磁碟 | 備份資料庫與上傳檔案 |

## 3. 移交包內容說明

客戶移交包資料夾名稱：

```text
JJ jig toolings customer handoff package
```

主要內容如下：

| 位置 | 用途 | 客戶需要知道的重點 |
| --- | --- | --- |
| `app/jig-toolings-management.jar` | 系統主程式 | 不需要打開，只由 bat 啟動 |
| `app/application.properties` | 系統設定 | 設定 MySQL 密碼、port、上傳資料夾 |
| `app/start-system.bat` | 啟動系統 | 每次要開系統就點這個 |
| `app/stop-system.bat` | 停止系統 | 需要關閉系統時使用 |
| `database/install-database.bat` | 安裝資料庫 | 第一次安裝時執行 |
| `database/schema.sql` | 資料表結構 | 給 MySQL 建立資料表用 |
| `database/default-users.sql` | 預設帳號 | 建立 admin、supervisor、engineer、operator |
| `scripts/backup-now.bat` | 手動備份 | 備份資料庫與上傳檔案 |
| `scripts/open-firewall-8080.bat` | 開啟防火牆 | 讓其他電腦可以連到主機 |
| `uploads/jigs` | 上傳檔案資料夾 | 治具圖片、圖紙、PDF、CAD 檔案存放處 |

## 4. 第一次安裝流程

### Step 1：複製移交包

將整個資料夾放到客戶主機，例如：

```text
C:\JJ-Jig-Toolings\
```

建議不要放在桌面，避免被誤刪。

### Step 2：安裝 Java 17

安裝完成後，開啟命令提示字元，輸入：

```bat
java -version
```

如果看到版本含有 `17`，代表 Java 可以使用。

### Step 3：安裝 MySQL Server 8.x

安裝時請記住 MySQL 的 `root` 密碼。  
MySQL Workbench 可以一起安裝，方便客戶 IT 查看資料，但系統本身不一定需要 Workbench 才能運作。

MySQL 安裝時會要求設定 root 密碼，請把這個密碼記錄下來。  
這個密碼不是系統登入密碼，而是系統連接資料庫時要用的「資料庫密碼」。

### Step 4：設定資料庫密碼

請設定系統連接 MySQL 的密碼。  
建議用 Windows 內建的記事本 Notepad 修改。

操作方式：

1. 進入移交包資料夾。
2. 打開 `app` 資料夾。
3. 找到 `application.properties`。
4. 在檔案上按滑鼠右鍵。
5. 選擇「開啟方式」→「記事本」。

如果看不到副檔名，檔案可能只顯示成 `application`，但類型會是 `PROPERTIES File`。

打開後，找到這兩行：

```text
spring.datasource.username=root
spring.datasource.password=
```

密碼要寫在 `spring.datasource.password=` 後面，中間不要加空格。

範例 1：如果 MySQL root 沒有密碼，保持空白：

```properties
spring.datasource.username=root
spring.datasource.password=
```

範例 2：如果 MySQL root 密碼是 `MyPassword123`，改成：

```properties
spring.datasource.username=root
spring.datasource.password=MyPassword123
```

範例 3：如果 MySQL 帳號不是 root，例如客戶 IT 建立帳號 `jigadmin`，就改成：

```properties
spring.datasource.username=jigadmin
spring.datasource.password=客戶設定的MySQL密碼
```

修改完成後：

1. 按鍵盤 `Ctrl + S` 儲存。
2. 關閉記事本右上角的 `X`。
3. 如果跳出「是否儲存變更」，請選「儲存」。

注意：不要把密碼寫到別的地方，也不要刪除 `=` 前面的文字。  
正確位置只有這一行：

```properties
spring.datasource.password=你的MySQL密碼
```

### Step 5：建立資料庫

執行：

```text
database\install-database.bat
```

系統會建立：

- `web_fixture_management` 資料庫
- 使用者資料表
- 治具/模具資料表
- 附件資料表
- 異動紀錄資料表
- 預設帳號

### Step 6：啟動系統

執行：

```text
app\start-system.bat
```

看到黑色視窗不要關掉。  
這個視窗就是系統正在運作的狀態。

### Step 7：打開系統

在主機上打開：

```text
http://localhost:8080
```

其他同事則使用：

```text
http://主機IP:8080
```

## 5. 預設帳號

第一次安裝後，系統提供以下帳號：

| 帳號 | 密碼 | 權限 | 用途 |
| --- | --- | --- | --- |
| `admin` | `123456` | ADMIN | 系統管理者，可管理帳號與所有資料 |
| `supervisor` | `123456` | SUPERVISOR | 主管，可修改與刪除所有治具/模具資料 |
| `engineer` | `123456` | ENGINEER | 工程人員，可新增與修改自己建立的資料 |
| `operator` | `123456` | OPERATOR | 操作人員，只能查詢、下載、匯出 |

重要：第一次登入後，請立刻修改密碼。

## 6. 權限說明

| 權限 | 可以做什麼 | 不建議做什麼 |
| --- | --- | --- |
| ADMIN | 建立帳號、修改角色、停用帳號、刪除檔案、核准報廢 | 不建議多人共用同一個 admin |
| SUPERVISOR | 修改/刪除所有治具與模具資料 | 不負責帳號管理 |
| ENGINEER | 新增資料、修改自己建立的資料、更換自己的附件 | 不能刪除整筆資料，不能修改別人的資料 |
| OPERATOR | 查詢、查看紀錄、下載檔案、匯出 CSV | 不能新增、修改、刪除 |

這樣設計的原因是：系統要能追蹤「誰在什麼時間做了什麼變更」。

## 7. 日常使用方式

一般使用流程：

```text
登入
  → 搜尋 Jig / Tooling
  → 查看詳細資料
  → 依權限更新狀態或到期日
  → 上傳或下載圖紙檔案
  → 查看異動紀錄
  → 匯出 CSV
```

建議客戶每天至少確認：

- 系統可以打開
- 使用者可以登入
- 附件可以下載
- 異動紀錄有正常記錄
- 備份有成功執行

## 8. 備份方式

執行：

```text
scripts\backup-now.bat
```

系統會備份兩種資料：

1. MySQL 資料庫：帳號、治具/模具資料、異動紀錄
2. 上傳檔案：圖片、圖紙、PDF、CAD 檔案

備份資料夾範例：

```text
backup\20260522-203000\
  web_fixture_management.sql
  uploads\
```

建議備份頻率：

| 使用狀況 | 建議頻率 |
| --- | --- |
| 每天多人使用 | 每天下班前備份 |
| 偶爾使用 | 每週備份 |
| 正式量產環境 | 交由客戶 IT 做自動備份 |

## 9. 內網連線與防火牆

如果主機自己可以開：

```text
http://localhost:8080
```

但是其他電腦不能開：

```text
http://主機IP:8080
```

通常是 Windows 防火牆擋住。

請用系統管理員身分執行：

```text
scripts\open-firewall-8080.bat
```

## 10. 常見問題

| 問題 | 可能原因 | 處理方式 |
| --- | --- | --- |
| 打不開 `localhost:8080` | 系統沒有啟動 | 執行 `app\start-system.bat` |
| 出現資料庫錯誤 | MySQL 密碼設定錯誤 | 修改 `app\application.properties` |
| 其他電腦連不上 | 防火牆擋住 8080 | 執行 `open-firewall-8080.bat` |
| `java` 不是內部或外部命令 | Java 沒安裝好或 PATH 未設定 | 重新安裝 Java 17 |
| 上傳檔案找不到 | `uploads/jigs` 被移動或刪除 | 還原備份資料夾 |
| 忘記密碼 | 需由 admin 重設 | 到 User Management 重設密碼 |

## 12. 建議交付說法

可以這樣向客戶說明：

> 這套系統安裝在一台 Windows 主機上，其他使用者不用安裝程式，只要用瀏覽器連到主機 IP 就能使用。資料存在 MySQL，圖片與圖紙存在 uploads 資料夾。每天只要備份資料庫和 uploads，就能保留完整資料。

如果客戶完全不懂程式，可以補一句：

> 平常不用打開程式碼，也不用開 VS Code。日常只需要會點 `start-system.bat`、登入系統、做備份，就能使用。
