ADMIN System owner or lead engineer 系統管理者或主管工程師 User management, approve scrap, add/edit jigs, update status/due date, view/download files, export CSV. 可管理帳號、核准報廢、新增/修改治具、更新狀態/到期日、檢視下載檔案、匯出 CSV。 None in the current first release. 第一版目前不限制。
SUPERVISOR Line leader or team supervisor 線長、組長或主管 Add/edit jigs across users, update status/due date, delete jigs/files, replace files, view logs, export CSV. 可跨使用者新增/修改治具、更新狀態/到期日、刪除治具/檔案、替換檔案、看紀錄、匯出 CSV。 Cannot manage users or approve Scrap. 不能管理帳號，也不能核准報廢。
ENGINEER Maintenance or process engineer 維修、製程或工程人員 View jigs, add/edit jig content, update non-scrap status/due date, view logs, download files, export CSV. 可檢視治具、新增/修改治具內容、更新非報廢狀態/到期日、看紀錄、下載檔案、匯出 CSV。 Cannot manage users, delete data, or scrap jigs. 不能管理帳號、刪除資料或報廢治具。
OPERATOR Production line or read-only user 產線或查詢型使用者 View jigs, view logs, download files, export CSV. 可檢視治具、看紀錄、下載檔案、匯出 CSV。 Read-only: cannot add, edit, delete, update status, or scrap jigs. 唯讀：不能新增、修改、刪除、更新狀態或報廢治具。
